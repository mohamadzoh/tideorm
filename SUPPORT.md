# Support

## Before You Ask

- Review the README and the relevant pages under `docs/` first.
- Search existing issues and pull requests for the same question or error.
- Re-check the behavior on the latest release or current `master` when practical.

## Where To Ask

- Bug or regression: open a bug report issue.
- Feature or API idea: open a feature request issue.
- Documentation problem: open a documentation issue.
- Usage question or troubleshooting help: open a question/support issue.
- Security vulnerability: do not open a public issue. Follow `SECURITY.md` instead.

## What To Include

To get a useful answer quickly, include:

- TideORM version, commit, or branch
- Database backend and runtime in use
- Enabled feature flags
- A minimal reproduction or reduced code sample
- Expected behavior and actual behavior
- Relevant error output, SQL preview, or logs

## Scope

This file covers help with using TideORM itself. Questions about unrelated infrastructure, unsupported forks, or third-party systems may be out of scope unless they expose a TideORM issue.
